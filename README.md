# Wortgarten

A small offline web app for learning German with the storybook *Mias Jahr in Freiburg* (100 stories, A1–A2).
One 50-minute session per story: review → new words → read & listen → write → speak.

Open it on a phone and choose "Add to Home screen" to install it.
Progress is stored on the device; use **Ich → Backup** to move it to another device.

`content.js` is generated from the storybook PDFs with the scripts in `tools/` (dump → parse → extras → gen).
